Como foi feito

Sem bibliotecas gráficas

Os pixels são acesos manualmente: a biblioteca só entrega o framebuffer.

Rasterização manual

Retas, circunferências e polígonos desenhados com DDA e Ponto Médio, um pixel por vez.

Matrizes homogêneas

Transformações 2D (3×3) e 3D (4×4) compostas e aplicadas com matrizes próprias.

Imagens PGM e PBM

Leitura, processamento e exportação de imagens nos formatos Netpbm em texto.

Web puro

HTML, CSS e JavaScript sem build: abra no navegador ou publique no GitHub Pages.
